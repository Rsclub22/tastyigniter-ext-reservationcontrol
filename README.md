# Reservation Control for TastyIgniter

Large-party rules, closure notes, internal booking pages and a JSON API for
[TastyIgniter](https://tastyigniter.com) 4 reservations.

- Extension code: `wagnersnetz.reservationcontrol`
- Package: `wagnersnetz/ti-ext-reservationcontrol`
- License: GPL-3.0-or-later

## Installation

```bash
composer require wagnersnetz/ti-ext-reservationcontrol
php artisan igniter:up
```
